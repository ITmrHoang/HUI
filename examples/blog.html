Dựng Web Components không framework: từ thẻ HTML đến design system

Một component tốt mở đúng những “cánh cửa” cho người dùng: thuộc tính, biến CSS, ::part, slot và :state(). Bài này đi qua từng cửa với ví dụ thật.

Quốc Bảo · · 9 phút đọc Web Components

Web Components là chuẩn của trình duyệt: Custom Elements đặt tên thẻ, Shadow DOM cô lập CSS, template + slot nhận nội dung. Không cần framework, thẻ chạy được ở mọi nơi có HTML.

1. Thuộc tính và property

Attribute luôn là chuỗi, property mang kiểu thật. Quy ước tốt là đồng bộ hai chiều (reflect) cho kiểu đơn giản, còn mảng/object chỉ nhận qua property.

class HuiCounter extends HuiElement { static properties = { /** Giá trị hiện tại */ value: { type: Number, default: 0 }, /** Bước nhảy */ step: { type: Number, default: 1 }, }; } defineElement('hui-counter', HuiCounter);
  • Boolean: có mặt = true; muốn tắt thì xóa attribute.
  • Tên attribute dạng kebab-case: maxCount ↔ max-count.

2. Biến CSS là cửa chính

Biến CSS kế thừa xuyên Shadow DOM. Đọc biến ngay tại chỗ dùng, đừng khai báo biến công khai trên :host:

.btn { border-radius: var(--hui-button-radius, var(--hui-radius)); } /* người dùng: */ .toolbar { --hui-button-radius: 999px; }

::part() cho những gì không có biến

hui-card::part(title) chọn được phần tử bên trong mà component chủ động đánh dấu part="title". Dùng kèm pseudo-class trạng thái được, nhưng không chọn sâu hơn bên trong part.

3. Trạng thái nội bộ với :state()

Attribute là dữ liệu đầu vào người dùng điều khiển; state là kết quả bên trong component.
hui-input:state(user-invalid)::part(container) { box-shadow: 0 0 0 3px var(--hui-danger-light); }

Mẹo: kết hợp :has() để tô cả nhóm trường khi ô bên trong lỗi.

4. Trợ năng không phải phần thêm

  1. Đúng role và tên (aria-label cho nút chỉ có icon).
  2. Điều khiển được hoàn toàn bằng bàn phím theo mẫu WAI-ARIA APG.
  3. Thông báo thay đổi qua vùng aria-live.

5. Đóng gói và phát hành

Mỗi component một entry để import lẻ, kèm một bản CDN một file cho người không dùng bundler:

npm i @itmrhoang/h-ui

Vậy là đủ để bắt đầu. Hãy thử mở mã nguồn trang này — nó chỉ là HTML thuần cộng các thẻ hui-*.
