H-UI theo các mẫu **WAI-ARIA Authoring Practices (APG)**: role + `aria-*` đúng chuẩn, điều khiển được hoàn toàn bằng
bàn phím, viền focus rõ (`:focus-visible`), thông báo thay đổi qua vùng `aria-live`. Mọi chuỗi mặc định (nút OK/Hủy,
"Không có dữ liệu", thông báo cho trình đọc màn hình…) đi qua hệ **locale** — có sẵn **tiếng Việt** (mặc định) và **English**.

> **English summary** — Built-in locales `vi` (default) and `en`. Switch with `setLocale('en')`, add languages with
> `registerLocale('ja', {...})` (missing keys fall back to English), or drop in `<hui-language-switch>`. Number / currency /
> date formatting follows the active locale via `Intl`. Keyboard support follows WAI-ARIA APG patterns.

## 1. Đổi ngôn ngữ (i18n)

```js
import { setLocale, registerLocale, getLocaleName, t } from '@itmrhoang/h-ui/core'; // hoặc từ '@itmrhoang/h-ui'

setLocale('en');                               // mọi component "localized" tự vẽ lại chữ
getLocaleName();                               // 'en'
t('pagination.total', { total: 50 });          // chuỗi theo ngôn ngữ hiện tại

// Thêm ngôn ngữ mới — key thiếu lấy từ 'en'
registerLocale('ja', { common: { ok: 'OK', cancel: 'キャンセル' }, empty: { description: 'データなし' } });
setLocale('ja');

// Sửa vài chuỗi của ngôn ngữ đang dùng
setLocale({ empty: { description: 'Chưa có gì ở đây' } });
```

- Đổi ngôn ngữ phát sự kiện `hui-locale-change` trên `document` (`e.detail.locale`) — trang của bạn nghe để đổi nội dung riêng.
- CDN: `HUI.setLocale('en')`.
- `<hui-language-switch>` có sẵn (dropdown hoặc `variant="inline"`), tự gọi `setLocale()`; `html-lang` để đồng bộ `<html lang>`.

```html
<hui-language-switch html-lang></hui-language-switch>
<hui-language-switch variant="inline" mode="code"></hui-language-switch>
```

**Định dạng số / tiền / ngày** theo locale (`Intl`, `vi` → `vi-VN`, `en` → `en-US`):

```js
import { formatCurrency, formatDate, relativeTime } from '@itmrhoang/h-ui/core';
formatCurrency(129000);             // "129.000 ₫" (vi) · "₫129,000" (en)
```

```html
<span data-bind="price" data-format="currency"></span>   <!-- trong <template> của component dữ liệu -->
<hui-time datetime="2026-10-20T09:00:00" format="relative"></hui-time>
<hui-price value="129000" original="159000" currency="VND"></hui-price>
```

## 2. Bàn phím (keyboard patterns)

| Loại component | Phím | Mẫu APG |
|----------------|------|---------|
| Nút, link, switch, checkbox | `Tab` focus · `Enter` / `Space` kích hoạt | Button, Checkbox, Switch |
| Menu, dropdown | `↑` `↓` di chuyển · `Home` / `End` · `Enter` chọn · `Esc` đóng, trả focus về nút mở · gõ chữ để nhảy | Menu Button |
| Tabs, segmented, radio | `←` `→` (dọc: `↑` `↓`) chuyển · `Home` / `End` · một điểm dừng `Tab` cho cả nhóm (roving tabindex) | Tabs, Radio Group |
| Select, autocomplete, mentions, command palette | Gõ để lọc · `↑` `↓` · `Enter` chọn · `Esc` đóng | Combobox + Listbox |
| Modal, drawer, cart drawer | Focus bị giữ trong hộp (focus trap) · `Esc` đóng lớp trên cùng · đóng xong trả focus | Dialog (Modal) |
| Tree, tree-select | `↑` `↓` · `→` mở / vào con · `←` đóng / ra cha · `Space` check · `*` mở cùng cấp | Tree View |
| Table | `Tab` vào tiêu đề sắp xếp / ô chọn · bảng `virtual`: phím mũi tên giữa các ô | Table / Grid |
| Kanban, sortable | `Space` nhấc · `↑` `↓` trong cột · `←` `→` sang cột · `Space` thả · `Esc` hủy (có thông báo `aria-live`) | Drag & drop bàn phím |
| Date / range / time picker, calendar | Mũi tên giữa các ngày · `PageUp` / `PageDown` tháng · `Enter` chọn · `Esc` đóng | Date Picker Dialog |
| Slider, rate, quantity | `←` `→` / `↑` `↓` · `Home` / `End` · `PageUp` / `PageDown` bước lớn | Slider, Spinbutton |
| Carousel, lightbox | `←` `→` · tự chạy dừng khi hover / focus | Carousel |
| Phím tắt toàn cục | `<hui-hotkey keys="mod+k">` · `registerHotkey()` — mặc định **không** bắt khi đang gõ trong ô nhập | — |

Chi tiết từng component nằm ở mục **Keyboard** trong docs của component đó.

## 3. ARIA & trình đọc màn hình

- Control không có nhãn hiển thị → đặt `label="…"` (chuyển thành `aria-label` bên trong) hoặc `aria-label` trên thẻ nút icon:
  `<hui-button shape="circle" icon="search" aria-label="Tìm kiếm"></hui-button>`.
- Form control nằm trong `<hui-form-item label="…">` tự được gắn nhãn; lỗi validate liên kết bằng `aria-describedby`.
- Thay đổi động (đã thêm vào giỏ, kéo thẻ, lọc xong "12 kết quả", lưu thất bại…) được đọc qua vùng `aria-live` ẩn.
- Ảnh trang trí để `alt=""`; ảnh nội dung luôn cần `alt`.

## 4. Chuyển động & hiển thị

- Mọi hiệu ứng **bật mặc định** nhưng tự tắt khi hệ điều hành bật **giảm chuyển động** (`prefers-reduced-motion`).
- Tắt từng thẻ: attribute `no-animation`; tắt cả trang: `<html data-hui-no-animation>` hoặc `--hui-motion-duration: 0ms`.
- Chế độ tương phản cao (`forced-colors`) giữ viền / focus rõ.
- Viền focus dùng token `--hui-focus-ring` — đổi màu được nhưng **đừng** xóa `outline` khi không có thay thế.
